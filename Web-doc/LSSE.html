LSSE Light-Scan Scripting Engine v1.0.6

13 Built-in Scripts HTTP/HTTPS DNS Extensible Extend Light-Scan with powerful reconnaissance scripts

Overview

The Light-Scan Scripting Engine (LSSE) is what makes Light-Scan a true mini-framework. It extends the core scanner's capabilities with 13 built-in scripts for web and DNS reconnaissance, security analysis, and information gathering.

Each script is designed to be modular and focused, performing a single task well. Scripts can be used independently or chained together for complex workflows.

Usage

Lightscan --lsse --script <name> [required_args] [optional_args]

# Examples:
Lightscan --lsse --script http-headers --domain google.com -sp 443
Lightscan --lsse --script dns-zone-transfer --domain example.com
Lightscan --lsse --script spider --url https://scanme.nmap.org --mxp 50 --mxd 3
Option Description
--lsse Enable LSSE scripting engine
--script SCRIPT Script to execute
--url URL Target URL for HTTP/HTTPS scripts
--domain DOMAIN Target domain for HTTP and DNS scripts
-sp SP Port(s) for scripts
--redirect Follow HTTP redirects
-W, --wordlist Wordlist for scripts
--extensions File extensions for web scripts
--starget Target IP or Domain name
--status-codes Status codes for web scripts
--mxp MXP Max pages to get (spider)
--mxd MXD Max depth to crawl (spider)
--dns-server DNS server for DNS scripts
--lsse-lst List all available scripts

Built-in Scripts

HTTP / HTTPS Scripts

1. spider

safe discovery --url
Category: safe/discovery/http_https • Required: --url • Optional: --mxd, --mxp
Recursively crawls websites for links, forms, and resources. Useful for mapping web applications and discovering hidden endpoints.
Lightscan --lsse --script spider --url https://scanme.nmap.org --mxp 50 --mxd 3

2. http-robots

safe discovery --domain, -sp
Category: safe/discovery/http_https • Required: --domain, -sp • Optional: None
Fetches and parses robots.txt for hidden paths and directories that the site owner has disallowed for crawlers.
Lightscan --lsse --script http-robots --domain example.com -sp 80

3. http-cert

safe analysis --domain, -sp
Category: safe/analysis/https • Required: --domain, -sp • Optional: None
Grabs SSL/TLS certificate information including issuer, validity period, SANs, and cipher suite details. Useful for security auditing.
Lightscan --lsse --script http-cert --domain google.com -sp 443

4. script

safe discovery --url
Category: safe/discovery/http_https • Required: --url • Optional: None
Detects <script> tags in HTML pages and extracts their sources. Useful for discovering JavaScript files and tracking external scripts.
Lightscan --lsse --script script --url https://example.com

5. http-title

safe discovery --domain, -sp
Category: safe/discovery/http_https • Required: --domain, -sp • Optional: --redirect
Extracts webpage titles from HTTP responses. Useful for identifying services, applications, and default pages.
Lightscan --lsse --script http-title --domain example.com -sp 80 --redirect

6. http-dir

medium discovery --url
Category: medium/discovery/http_https • Required: --url • Optional: --wordlist, --status-codes, --extensions
Brute forces directories and files on web servers using a wordlist. Supports custom extensions and status code filtering.
Lightscan --lsse --script http-dir --url http://192.168.1.1 -W common.txt --extensions php,html,txt

7. http-headers

safe analysis --domain, -sp
Category: safe/analysis/http_https • Required: --domain, -sp • Optional: --redirect
Fetches HTTP headers and checks for missing security headers including: HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and X-XSS-Protection.
Lightscan --lsse --script http-headers --domain google.com -sp 443

8. http-methods

safe discovery --domain, -sp
Category: safe/discovery/http_https • Required: --domain, -sp • Optional: None
Checks which HTTP methods are allowed by the server. Identifies safe methods (GET, HEAD, POST) and dangerous methods (PUT, DELETE, TRACE, OPTIONS).
Lightscan --lsse --script http-methods --domain example.com -sp 80

9. http-cookie

safe analysis --domain, -sp
Category: safe/analysis/http_https • Required: --domain, -sp • Optional: --redirect
Checks cookies for Secure and HttpOnly flags. Identifies session cookies that may be vulnerable to theft.
Lightscan --lsse --script http-cookie --domain example.com -sp 443

DNS Scripts

10. dns-lookup

safe discovery --domain
Category: safe/discovery/dns • Required: --domain • Optional: --dns-server
Fast DNS lookup for IPv4 and IPv6 addresses. Resolves domain names to IP addresses and shows all associated A and AAAA records.
Lightscan --lsse --script dns-lookup --domain google.com

11. dns-ns

safe discovery --domain
Category: safe/discovery/dns • Required: --domain • Optional: --dns-server
Gets the Name-Server (NS) records of a domain. Identifies authoritative DNS servers for the target domain.
Lightscan --lsse --script dns-ns --domain example.com

12. dns-subdomain-fuzzing

medium discovery --domain
Category: medium/discovery/dns • Required: --domain • Optional: --wordlist, --dns-server
Brute forces subdomains using a wordlist. Identifies hidden subdomains and potential attack surfaces. Useful for reconnaissance and asset discovery.
Lightscan --lsse --script dns-subdomain-fuzzing --domain example.com -W subdomains.txt

13. dns-zone-transfer

medium extracting --domain
Category: medium/extracting/dns • Required: --domain • Optional: --dns-server
Attempts an AXFR zone transfer to enumerate all DNS records for a domain. This is a classic information disclosure vulnerability when misconfigured DNS servers allow zone transfers.
Lightscan --lsse --script dns-zone-transfer --domain example.com

Firewalls Scripts

14. firewall-detection

medium analysis --starget,-sp
Category: medium/analysis/firewall • Required: --starget,-sp • Optional: None
Firewall detection using multiple probe techniques on a single port
Lightscan --lsse --script firewall-detection -sp 80 --starget scanme.nmap.org

Creating Custom Scripts

LSSE is designed to be extensible. You can create your own scripts and integrate them into the framework. Follow the steps below to add a new script.

Step 1: Choose a Location for Your Script

LSSE scripts are organized by category in the LSSE/scripts/ directory. Choose the appropriate folder based on your script's purpose:

Category Path Description
Safe / Discovery LSSE/scripts/safe/discovery/ Non-intrusive information gathering scripts
Safe / Analysis LSSE/scripts/safe/analysis/ Non-intrusive security analysis scripts
Safe / Extracting LSSE/scripts/safe/extracting/ Non-intrusive data extraction scripts
Medium / Discovery LSSE/scripts/medium/discovery/ More aggressive discovery scripts (may generate traffic)
Medium / Analysis LSSE/scripts/medium/analysis/ More aggressive analysis scripts
Medium / Extracting LSSE/scripts/medium/extracting/ More aggressive data extraction scripts
Harmful LSSE/scripts/harmful/ Scripts that could cause damage (use with caution)
LSSE/scripts/safe/discovery/http_https/ → For safe HTTP/HTTPS discovery scripts
LSSE/scripts/medium/discovery/dns/ → For medium DNS discovery scripts

Step 2: Create Your Script File

Create a Python file in the appropriate directory. Name it descriptively, e.g., my_custom_script.py.

Script Template

#!/usr/bin/env python3
"""
Light-Scan Scripting Engine (LSSE)
Script Name : dns-subdomain-fuzzing
Author : Adam Boulaaz
Arguments
--> Required Arguments
----> --starget
----> -sp
--> Optional Arguments
----> --verbose
Categorie : ....
"""

import sys

def main(target, port=None, verbose=False, **kwargs):
    """
    Main function for your script.

    Args:
        target (str): The target (domain, URL, or IP)
        port (int, optional): Port number
        verbose (bool, optional): Enable verbose output
        **kwargs: Additional arguments passed from LSSE

    Returns:
        dict or None: Results of the script
    """
    print(f"[*] Running my-custom-script on {target}")

    # Your script logic here
    # ...

    # Return results if needed
    return {"status": "success", "target": target, "port": port}

Step 3: Import Your Script in lsse.py

Open LSSE/lsse.py and add your script to the scripts_list and the script_list() method.

Add to scripts_list

class LSSE:
    def __init__(self):
        self.scripts_list = [
            "http-title",
            "http-robots",
            # ... existing scripts ...
            "my-custom-script"  # ← Add your script here
        ]

Add to script_list() Method

def script_list(self, sname, t=None, ports=None, redirect=None, domain=None, dns=None, wordlist=None, url=None, max_pages=None, max_depth=None, extensions=None, status_codes=None):
    if sname in self.scripts_list:
        match sname:
            # ... existing cases ...
            case "my-custom-script":
                from LSSE.scripts.safe.discovery.http_https.my_custom_script import main
                main(
                    target=domain or url,
                    port=ports[0] if ports else None,
                    verbose=True
                )
            case _:
                print(f"\n{yellow}[!] Script not found {reset}\n")
                sys.exit(2)
    else:
        print(f"\n{yellow}[!] Script not found {reset}\n")
        sys.exit(3)

Step 4: Add Arguments to Lightscan.py (If Needed)

If your script requires custom arguments that aren't already available, you'll need to add them to Lightscan.py in the args_parse() method.

Add Custom Argument

def args_parse(self):
    self.parser = argparse.ArgumentParser(description="Light-Scan Port Scanner")
    # ... existing arguments ...
    self.parser.add_argument("--my-arg", type=str, help="Custom argument for my script")
    # ... more arguments ...
    self.args = self.parser.parse_args()

Parse and Pass to LSSE

# In the Start() method, where LSSE is called:
lsse.Lsse.script_list(
    self.args.script,
    t=self.args.starget,
    ports=self.lsse_ports_to_scan,
    redirect=self.args.redirect,
    domain=self.args.domain,
    dns=self.args.dns_server,
    wordlist=self.args.wordlist,
    url=self.args.url,
    max_pages=self.args.mxp,
    max_depth=self.args.mxd,
    extensions=self.args.extensions,
    status_codes=self.args.status_codes,
    my_arg=self.args.my_arg  # ← Pass your custom argument
)

Step 5: Update --lsse-lst Description

To make your script visible in the --lsse-lst output, update the description in Lightscan.py:

Add Script Description

if self.args.lsse_lst:
    print(f\"\"\"
{green}[+] LSSE Scripts (LightScan Scripting Engine){reset}
{'-' * 50}

# ... existing scripts ...

{yellow}[15] my-custom-script{reset}
    Required:   --domain
    Optional:   --my-arg, --dns-server
    Category:   safe/discovery/http_https
    Description: Briefly describe what your script does

{'-' * 50}
{green}[+] Usage: Lightscan --lsse --script  {reset}
    \"\"\")
    sys.exit(0)

Step 6: Test Your Script

Lightscan --lsse --script my-custom-script --domain example.com --my-arg "value" Run your custom script

Contributing Your Script

If you've created a script that you think would be useful to the community, you can fork the repository and submit a pull request. Here's how:

  1. Fork the Light-Scan repository on GitHub
  2. Add your script following the steps above
  3. Test your script thoroughly
  4. Submit a pull request with a clear description of your script

The developer may review and add your script to the official LSSE distribution if it:

  • Works correctly without errors
  • Fits the LSSE architecture and coding standards
  • Provides useful functionality for the community
  • Has proper documentation and help text
git clone https://github.com/YOUR_USERNAME/Light-Scan.git Clone your fork
git checkout -b my-custom-script Create a new branch
git add LSSE/scripts/... Add your script files
git commit -m "Add my-custom-script to LSSE" Commit your changes
git push origin my-custom-script Push your branch
Open a Pull Request on GitHub Submit for review
