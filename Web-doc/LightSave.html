LightSave Light-Scan Results Exporter v1.0.1

Results Exporter 8 Formats Automated Capture Lightscan output and save in structured formats

Overview

LightSave is a dedicated result exporter that captures the output of any Lightscan command and saves it in a structured format. It supports 8 export formats and is designed for easy integration with reporting pipelines, SIEM systems, and security documentation workflows.

📊 8 Export Formats

  • LIGHT — Native Light-Scan format
  • TXT — Plain text (human-readable)
  • HTML — Web-friendly reports
  • XML — Machine-readable structured data
  • CSV — Spreadsheet-ready tables
  • JSON — API-ready structured data
  • PDF — Professional printable reports
  • YAML — Human-readable structured data

⚡ Key Features

  • Captures any Lightscan command output
  • Automated saving with timestamps
  • Machine-readable output for automation
  • Clean, well-formatted files
  • Integrated with LightPanel GUI
  • Cross-platform (Windows, Linux, macOS, BSD)

Command-Line Options

Option Required Description
-C C Yes Full Lightscan command (must be enclosed in quotes)
-S {txt,light,html,xml,csv,json,pdf,yaml} Yes Export format
LightSave -C "Lightscan -T 192.168.1.1 -F" -S html Save scan results as HTML report

Export Formats

1. LIGHT — Native Format

The LIGHT format is Light-Scan's native output format. It preserves the exact console output with color codes and formatting, making it ideal for archiving and debugging.

[+] Light-Scan v1.1.8 [*] Scan completed in 2.08 seconds [*] Total Time in 2.12 seconds ============================================================ [+] Scan result for : 192.168.1.1 [+] Scan Type: SYN | Protocol: TCP [+] Reverse DNS: None [+] IP Status: Local [+] Mac Address: aa:bb:cc:dd:ee:ff ============================================================ [+] Open Ports: 4 Port 135 msrpc\tcp Port 139 netbios-ssn\tcp Port 445 microsoft-ds\tcp Port 5357 wsdapi\tcp

2. TXT — Plain Text

The TXT format provides clean, human-readable plain text output. Ideal for documentation and quick viewing.

3. HTML — Web Reports

The HTML format generates a styled, web-friendly report. Perfect for sharing with non-technical stakeholders or publishing to internal portals.

4. XML — Machine-Readable

The XML format provides structured data for parsing by other tools and systems. Ideal for SIEM integration and automated processing.

<?xml version="1.0" encoding="UTF-8"?> <scan_results> <target> <ip>192.168.1.1</ip> <scan_type>SYN</scan_type> <protocol>TCP</protocol> <open_ports> <port number="135">msrpc</port> <port number="139">netbios-ssn</port> <port number="445">microsoft-ds</port> <port number="5357">wsdapi</port> </open_ports> </target> </scan_results>

5. CSV — Spreadsheet-Ready

The CSV format exports results as comma-separated values, perfect for importing into spreadsheets, databases, and data analysis tools.

Target,Port,Service,State,Protocol 192.168.1.1,135,msrpc,open,tcp 192.168.1.1,139,netbios-ssn,open,tcp 192.168.1.1,445,microsoft-ds,open,tcp 192.168.1.1,5357,wsdapi,open,tcp

6. JSON — API-Ready

The JSON format provides structured data in a lightweight, machine-readable format. Ideal for APIs, automation, and modern tools.

{ "scan_results": [ { "target": "192.168.1.1", "scan_type": "SYN", "protocol": "TCP", "open_ports": [ {"port": 135, "service": "msrpc"}, {"port": 139, "service": "netbios-ssn"}, {"port": 445, "service": "microsoft-ds"}, {"port": 5357, "service": "wsdapi"} ] } ] }

7. PDF — Professional Reports

The PDF format generates a professionally formatted report that is perfect for documentation, client deliverables, and compliance reporting.

8. YAML — Human-Readable Structured Data

The YAML format provides structured data that is both machine-readable and human-friendly. Ideal for configuration and documentation.

scan_results: - target: 192.168.1.1 scan_type: SYN protocol: TCP open_ports: - port: 135 service: msrpc - port: 139 service: netbios-ssn - port: 445 service: microsoft-ds - port: 5357 service: wsdapi

Usage Examples

Basic Scanning & Export

LightSave -C "Lightscan -T 192.168.1.1 -F" -S html Save scan results as HTML report
LightSave -C "Lightscan -T 192.168.1.1 -F -st UDP" -S xml Save UDP scan results as XML
LightSave -C "Lightscan -T scanme.nmap.org -p 22,80,443" -S json Save scan results as JSON for automation

Advanced Scanning & Export

LightSave -C "Lightscan -T 192.168.1.1 -O -b" -S pdf Save OS and banner grab results as PDF
LightSave -C "Lightscan -T 192.168.1.0/24 -s fast -F" -S csv Save network scan as CSV for analysis
LightSave -C "Lightscan -T 10.0.0.0/16 -st SYN -t 200 -tm 0.5" -S yaml Save large scan results as YAML

LSSE Scripts & Export

LightSave -C "Lightscan --lsse --script http-headers --domain google.com -sp 443" -S json Save HTTP headers analysis as JSON
LightSave -C "Lightscan --lsse --script dns-zone-transfer --domain example.com" -S xml Save DNS zone transfer results as XML

With LightPanel GUI

Generate professional reports in HTML or PDF for client deliverables:

LightSave -C "Lightscan -T 192.168.1.1 -O -b -A" -S pdf Generate comprehensive PDF report

Troubleshooting

❌ "LightSave: error: argument -C is required"

The -C option is required. You must specify a Lightscan command.

LightSave -C "Lightscan -T 192.168.1.1" -S html

❌ "LightSave: error: argument -S is required"

The -S option is required. You must specify an export format.

LightSave -C "Lightscan -T 192.168.1.1" -S json

❌ "Invalid format"

Valid formats are: txt, light, html, xml, csv, json, pdf, yaml.
