Overview

LightSniff is a lightweight, feature-rich packet sniffer built for network analysis and troubleshooting. It leverages BPF (Berkeley Packet Filter) syntax for precise traffic filtering and supports both live capture and PCAP export.

🔍 Key Features

  • Live packet capture with BPF filtering
  • Protocol filtering: TCP, UDP, ICMP, ARP
  • MAC address filtering
  • VLAN tag detection (802.1Q)
  • TLS/SSL detection (1.0, 1.1, 1.2, 1.3, SSLv3)
  • HTTP traffic detection and parsing
  • DNS query/response detection

💾 File Support

  • Save to PCAP, PCAPNG, and LightBin (.lbn)
  • Read from PCAP, PCAPNG, and LightBin (.lbn)
  • zlib compression for LightBin files
  • Ethernet frame info (MAC addresses, frame type)
  • Auto-interface detection
  • Promiscuous mode support

Command-Line Options

Option Description
-h, --help Show this help message and exit
-i, --interface INTERFACE Network interface (e.g., eth0, Wi-Fi, wlan0)
-I, --interfaces Show all available Network Interfaces
-f, --filter FILTER BPF filter (e.g., 'tcp port 80', 'icmp', 'arp')
-c, --count COUNT Number of packets to capture (0 = infinite)
-w, --write WRITE Save to PCAP/PCAPNG file
-r, --read READ Read packets from PCAP/PCAPNG file (offline mode)
--bin-save BIN_SAVE Save to LightBin binary format (.lbn)
--bin-load BIN_LOAD Load from LightBin binary format (.lbn)
-C, --compress To compress saved output (only for .lbn)
-v, --verbose Show detailed packet info
--no-promisc Disable promiscuous mode
-q, --quiet Quiet mode (no banner)
--eth Show Ethernet frame info (MAC addresses, frame type)
--vlan Show VLAN tags (802.1Q)
--arp Show only ARP packets
--tcp Show only TCP packets
--udp Show only UDP packets
--icmp Show only ICMP packets
--mac MAC Filter by source or destination MAC address (e.g., aa:bb:cc:dd:ee:ff)

Usage Examples

Basic Capture

LightSniff -i eth0 Capture all traffic on interface eth0
LightSniff -i Wi-Fi -c 100 -v Capture 100 packets with verbose output
LightSniff -I Show all available network interfaces

Protocol Filtering

LightSniff -i eth0 --tcp --udp --icmp Capture TCP, UDP, and ICMP packets together
LightSniff -i eth0 --arp --eth Show ARP packets with Ethernet frame details
LightSniff -i eth0 --mac aa:bb:cc:dd:ee:ff Filter by MAC address

BPF Filtering

LightSniff -i eth0 -f 'tcp port 80' -w http.pcap Capture HTTP traffic and save to PCAP
LightSniff -i eth0 -f 'icmp' Capture only ICMP traffic
LightSniff -i eth0 -f 'arp' Capture only ARP traffic
LightSniff -i eth0 -f 'tcp port 80 or tcp port 443' Capture HTTP and HTTPS traffic

File Operations

LightSniff -i eth0 -c 100 -w capture.pcap Save 100 packets to PCAP file
LightSniff -r capture.pcap -v Read and display PCAP file
LightSniff -i eth0 -c 100 --bin-save capture.lbn -C Capture and save as LightBin with compression
LightSniff --bin-load capture.lbn -v Load and display LightBin file
LightSniff --bin-load capture.lbn -w output.pcap Load LightBin and save as PCAP
LightSniff -r input.pcap --bin-save output.lbn -C Read PCAP and save as LightBin with compression

LightBin Integration

LightSniff fully supports LightBin (.lbn), Light-Scan's native binary packet format. LightBin files load 1.2–2× faster than PCAP and store rich metadata including capture arguments, statistics, and packet types.

⚡ Benefits of LightBin

  • Faster loading: 1.2–2× faster than PCAP
  • Rich metadata: Stores args, stats, tool version
  • Compression: zlib compression support
  • Checksum: CRC32 integrity verification
  • Auto-detection: Smart packet type detection

💾 LightBin Commands

--bin-save capture.lbn Save to LightBin
--bin-load capture.lbn Load from LightBin
-C, --compress Compress LightBin output
LightSniff -i eth0 -c 1000 --bin-save capture.lbn -C Capture 1000 packets, save as compressed LightBin

Troubleshooting

❌ "No interface specified"

You must specify an interface with -i or use -I to list available interfaces.

LightSniff -I List all interfaces

❌ "Permission denied"

Packet capture requires administrative/root privileges. Run as Administrator (Windows) or with sudo (Linux/macOS).

sudo LightSniff -i eth0 Linux/macOS

❌ "No packets captured"

Try disabling promiscuous mode with --no-promisc or check if the interface is up and receiving traffic.

LightSniff -i eth0 --no-promisc

❌ "Invalid filter"

BPF filter syntax must be correct. Common filters: 'tcp port 80', 'icmp', 'arp'.
