Overview

Lightscan is the heart of the Light-Scan toolkit — a high-performance, multi‑threaded port scanner built with Python and Scapy. It is designed to deliver enterprise‑grade network reconnaissance in a lightweight, flexible package.

Unlike traditional scanners that sacrifice accuracy for speed or vice versa, Lightscan strikes a careful balance. It supports 14 distinct scan types, from standard TCP Connect and SYN Stealth to advanced techniques like FDD (Firewall Detection Scan) — a proprietary scan type exclusive to Light-Scan.

Lightscan also features 12 host discovery methods, including ICMP Echo, Timestamp, Address Mask, and the rare Information (Type 15) and Solicitation (Type 10) pings — both of which are not supported by Nmap. By default, Lightscan performs ICMP Echo (IPv4) and ICMPv6 Echo (IPv6) without requiring any additional flag. With 6 speed presets (from 2 to 500 threads), custom packet crafting (TTL, HLIM, source port, payload, IP ID, and flags), and a +11500 port‑to‑service mapping database, Lightscan gives you complete control over every scan.

FDD — Firewall Detection Scan

FDD (Firewall Detection Scan) is a proprietary scanning technique developed exclusively for Lightscan. It sends a TCP packet with the URGENT (URG) flag to determine whether a firewall is protecting the target port. The URG flag is rarely used in legitimate traffic, making it an excellent probe for firewall detection. By analysing the response (or lack thereof), Lightscan can determine if a firewall is actively filtering the port.

Response Interpretation

Response TypeClassificationExplanation
RST or RST-ACKUndefended PortPort responded directly — no firewall interference
No ResponseDefended PortNo response suggests a firewall is blocking the probe
ICMP Type 3, Code 1,2,3,9,10,13Defended PortICMP error indicates a firewall is actively rejecting the packet

FDD Usage

Lightscan -T 192.168.1.1 -p 443 -st FDDRun FDD on a single port
Lightscan -T 192.168.1.1 -p 22,80,443,8080 -st FDDScan multiple ports with FDD
Lightscan -T 192.168.1.1 -p 1-1000 -st FDD -vFDD on a port range with verbose output
