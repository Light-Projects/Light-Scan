LightLab Light-Scan Packet Crafting Laboratory v1.0.1

Packet Crafting Interactive 11+ Layers Build custom packets layer by layer, send them, and save to PCAP or LightBin

Overview

LightLab is an interactive packet crafting laboratory that allows users to build custom packets from scratch using a simple command-line interface. It supports all major protocol layers and includes built-in templates for common network operations.

🧪 Key Features

  • Build packets from scratch with new command
  • Set parameters with set
  • View packet structure with show
  • Send packets with send (count + verbose)
  • Save/load PCAP, PCAPNG, and LightBin files
  • Built-in templates for common operations
  • Interactive shell with command history

📦 Supported Layers

  • Ethernet: ether
  • VLAN: vlan (802.1Q)
  • ARP: arp
  • IPv4: ip
  • IPv6: ipv6
  • TCP: tcp
  • UDP: udp
  • ICMP: icmp
  • ICMPv6: icmpv6, icmpv6_echo
  • NDP: ndp_rs, ndp_ra, ndp_na, ndp_ns
  • HTTP: http
  • DNS: dns
  • SSH: ssh
  • Raw: raw

Commands

Command Description
new <layer> Add a layer: ether, vlan, arp, ip, ipv6, tcp, udp, icmp, ndp_rs, ndp_ra, ndp_na, ndp_ns, icmpv6, icmpv6_echo, http, dns, ftp, ssh, raw
delete <layer> Delete a layer
params <layer> Show available parameters for a layer
set <layer>.<param>=<value> Set a parameter value
show Show current packet structure
clear Clear all layers
send [count] [-v] Send packet (count=number, -v=verbose)
timeout <seconds> Set response timeout
interval <seconds> Set interval time between packets
templates Show example configurations
history Show command history
help Show help message
exit Quit LightLab
save <filename.pcap/.pcapng> Save current packet to PCAP/PCAPNG
load <filename.pcap/.pcapng> Load packet from PCAP/PCAPNG
savebin <filename.lbn> Save current packet to LightBin
loadbin <filename.lbn> Load packet from LightBin

Layer Parameters

Ethernet (ether)

dst — Destination MAC address src — Source MAC address type — Ethertype (e.g., 0x0800 for IPv4)

VLAN (vlan)

prio — Priority (0-7) vlan — VLAN ID (1-4094) dei — Drop Eligible Indicator type — Ethertype

ARP (arp)

hwtype — Hardware type (1 = Ethernet) ptype — Protocol type (0x0800 = IPv4) hwlen — Hardware address length (6) plen — Protocol address length (4) op — Operation (1=request, 2=reply) hwsrc — Sender MAC address psrc — Sender IP address hwdst — Target MAC address pdst — Target IP address

IPv4 (ip)

dst — Destination IP address src — Source IP address ttl — Time To Live (1-255) id — Identification field flags — IP flags (DF=2, MF=1) proto — Protocol number (6=TCP, 17=UDP) version — IP version (4) ihl — Internet Header Length len — Total length tos — Type of Service frag — Fragment offset chksum — Header checksum

IPv6 (ipv6)

dst — Destination IPv6 address src — Source IPv6 address hlim — Hop Limit (1-255) nh — Next Header (6=TCP, 17=UDP, 58=ICMPv6) version — IP version (6) tc — Traffic Class fl — Flow Label plen — Payload Length

TCP (tcp)

dport — Destination port sport — Source port seq — Sequence number ack — Acknowledgment number flags — TCP flags (S, A, F, R, P, U) window — Window size options — TCP options (MSS, WScale, etc.) dataofs — Data offset chksum — Checksum urgptr — Urgent pointer

UDP (udp)

dport — Destination port sport — Source port len — Length chksum — Checksum

ICMP (icmp)

type — ICMP type (8=Echo Request, 0=Echo Reply) code — ICMP code id — Identifier seq — Sequence number chksum — Checksum ts_ori — Timestamp (original) ts_rx — Timestamp (received) ts_tx — Timestamp (transmitted) gw — Gateway address ptr — Pointer reserved — Reserved field addr_mask — Address mask nexthopmtu — Next-hop MTU unused — Unused field extpad — Extension padding ext — Extension

ICMPv6 (icmpv6)

type — ICMPv6 type code — ICMPv6 code cksum — Checksum msgbody — Message body

ICMPv6 Echo (icmpv6_echo)

type — ICMPv6 type (128=Echo Request, 129=Echo Reply) code — ICMPv6 code cksum — Checksum id — Identifier seq — Sequence number data — Data payload

NDP Router Solicitation (ndp_rs)

type — ICMPv6 type (133) code — ICMPv6 code (0) cksum — Checksum res — Reserved field

NDP Router Advertisement (ndp_ra)

type — ICMPv6 type (134) code — ICMPv6 code (0) cksum — Checksum chlim — Cur Hop Limit M — Managed address configuration flag O — Other configuration flag H — Home agent flag P — Proxy flag prf — Default router preference res — Reserved field reachabletime — Reachable time (milliseconds) retranstimer — Retransmission timer (milliseconds) routerlifetime — Router lifetime (seconds)

NDP Neighbor Solicitation (ndp_ns)

type — ICMPv6 type (135) code — ICMPv6 code (0) cksum — Checksum res — Reserved field tgt — Target IPv6 address

NDP Neighbor Advertisement (ndp_na)

type — ICMPv6 type (136) code — ICMPv6 code (0) cksum — Checksum res — Reserved field R — Router flag S — Solicited flag O — Override flag tgt — Target IPv6 address

DNS (dns)

id — DNS transaction ID qr — Query/Response flag (0=query, 1=response) opcode — Operation code aa — Authoritative Answer flag tc — Truncation flag rd — Recursion Desired flag ra — Recursion Available flag z — Reserved (zero) field rcode — Response code qdcount — Question count ancount — Answer count nscount — Authority count arcount — Additional count qd — Question section (DNSQR) an — Answer section (DNSRR) ns — Authority section (DNSRR) ar — Additional section (DNSRR)

HTTP (http)

Method — GET, POST, PUT, DELETE, HEAD, OPTIONS Path — Request path (e.g., /, /index.html) Http_Version — HTTP/1.0, HTTP/1.1, HTTP/2 Host — Host header (e.g., example.com) Connection — Keep-Alive, Close Content_Type — application/json, text/html, etc. Content_Length — Content length in bytes User_Agent — User-Agent string Cookie — Cookie header Referer — Referer header Accept — Accept header Accept_Language — Accept-Language header Accept_Encoding — Accept-Encoding header Upgrade_Insecure_Requests — Upgrade-Insecure-Requests header Origin — Origin header Cache_Control — Cache-Control header Pragma — Pragma header Authorization — Authorization header X_Forwarded_For — X-Forwarded-For header Proxy_Authorization — Proxy-Authorization header Proxy_Connection — Proxy-Connection header Keep_Alive — Keep-Alive header X_Wap_Profile — X-Wap-Profile header X_Request_ID — X-Request-ID header DNT — Do Not Track header TE — TE header Date — Date header Upgrade — Upgrade header X_ATT_DeviceId — X-ATT-DeviceId header X_Correlation_ID — X-Correlation-ID header X_Csrf_Token — X-Csrf-Token header X_Forwarded_Host — X-Forwarded-Host header X_Forwarded_Proto — X-Forwarded-Proto header X_Http_Method_Override — X-Http-Method-Override header X_Requested_With — X-Requested-With header X_UIDH — X-UIDH header Unknown_Headers — Additional custom headers Content_MD5 — Content-MD5 header

SSH (ssh)

packet_length — Packet length (4 bytes) padding_length — Padding length (1 byte) padding — Padding bytes data — Data payload

Raw (raw)

load — Raw payload data (bytes or string)

Templates

LightLab includes built-in templates for common packet crafting operations. Use the templates command to list them, or follow the examples below.

1. TCP SYN Scan

LightLab> new ip
LightLab> set ip.dst=192.168.1.1
LightLab> new tcp
LightLab> set tcp.dport=80
LightLab> set tcp.flags=S
LightLab> send -v

LightLab> new ip

LightLab> new tcp
LightLab> set tcp.dport=80

LightLab> set http.Host=example.com
LightLab> send -v

3. HTTP POST Request

LightLab> new ip
LightLab> set ip.dst=example.com
LightLab> new tcp
LightLab> set tcp.dport=80

LightLab> set http.Path=/login
LightLab> set http.Host=example.com
LightLab> set http.Content_Type=application/x-www-form-urlencoded

LightLab> set raw.load=username=admin&password=test

4. UDP DNS Query

LightLab> new ip

Troubleshooting

❌ "No such layer"

Use params to see available parameters for a layer. Available layers: ether, vlan, arp, ip, ipv6, tcp, udp, icmp, ndp_rs, ndp_ra, ndp_na, ndp_ns, icmpv6, icmpv6_echo, http, dns, ssh, raw.

❌ "Permission denied"

Sending packets requires administrative/root privileges. Run as Administrator (Windows) or with sudo (Linux/macOS).

❌ "No response received"

Check that the target is reachable and that you have the correct interface. Use timeout to increase the response wait time.
